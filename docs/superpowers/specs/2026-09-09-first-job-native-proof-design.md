# Hosted native first-job proof

The approved proof extends the existing joined onboarding fixture. A GitHub macOS
runner builds a separately named fixture app and runs a real local relay backed
by owned PostgreSQL, Redis and MinIO processes. Service versions, source hashes
and the Go compiler are pinned. Docker, external infrastructure, real credentials
and payments are excluded. Relay object-store admission remains enabled.

Actual onboarding must preserve the reviewed canonical company profile. The
fresh account has Scout only. The normal inline Approve team and start action
publishes owner approval, invokes the new native idempotent preparation and
creates the worker, rank and membership. The driver does not repair or pre-staff
that path. The deterministic provider only returns model responses; bundled CLI,
signing, relay admission, task transitions and native process isolation are real.

One task, worker, approval receipt and instruction survive reload. Provider requests cannot
begin before the owner approval and team receipt are stored. Worker output and
Scout review must be visible and signed in the original thread; both live cards
must observe completed state before reload. Evidence includes source/binary
hashes, scoped signed records and successful cleanup, explicitly labelled as
synthetic provider and seeded isolated ledger, not live payment/model-quality proof.

The existing private TLS transport and outbound browser guard remain unchanged.
All execution is on GitHub; unavailable backing services fail the gate rather
than converting it to a successful skip. This follow-up must not merge before
its first-job feature dependency (#669) and its own applicable checks pass.

The actor check uses the exact own `[System]` persona section against the actual
signed kind30175 definitions, then verifies signed30177 ranks/manager and the
returned signed message pubkeys. No marker is inserted into agent prompts.

ranks therefore need not appear in the model work context. The proof records
this limitation and never fabricates employee heads to make the assertion pass.
