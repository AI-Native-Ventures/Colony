# Rich preview samples

These deterministic, locally authored fixtures exercise the actual media viewers.

- `launch-01.svg`, `launch-02.svg`, `launch-03.svg`: square, portrait and landscape original SVG images for an ordered carousel.
- `preview-video.mp4`: six seconds, including a two-second black leader followed by a geometric teal frame. No audio track.
- `preview-video-poster.jpg`: the visible three-second frame from that same video.
- `preview-audio.wav`: a quiet six-second 440 Hz tone with short fades, for playback and seek controls.

- `service-ledger.csv`: 32 source entries plus headers, including quoted commas, with four columns.
- `service-ledger.xlsx`: Revenue and Summary sheets, formatted currency, saved formula values and an explicitly unavailable unsaved calculation.
- `service-report.pdf`: two pages with real searchable report and next-week text.

These are samples, not generated customer work. Assets have no external requests, embedded scripts, or third-party rights.
